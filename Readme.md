# 🚀 Team Retro Board  
A clean, fast, and interactive retrospective board for agile teams.  
Built by **Thread Racers** — Week 4 Final Deliverable.

---

## 📌 Overview  
Team Retro Board is a lightweight retrospective tool that allows teams to track:

- ✅ What went well  
- ⚠️ What needs improvement  
- 🔥 Action items needed  

It supports voting, sorting, search, CSV/PDF/JSON exports, keyboard shortcuts, and a live dashboard summary.

---

## 🌟 Features  

### 📝 Core Features  
- Add, edit, delete retro notes  
- Upvote/downvote  
- Filter & sort  
- Search across all columns  
- Export: CSV, PDF, JSON  
- Real-time dashboard (bar chart)  
- Auto timestamps & user names
